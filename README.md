## 📌 Project Overview

This project is an interactive **Healthcare Data Analytics Dashboard** developed for **Papollo Hospitals** using Microsoft Power BI.

The dashboard transforms healthcare-related operational data into an interactive visual reporting solution, allowing users to analyze important areas such as:

- Patient information
- Hospital admissions
- Discharge activity
- Follow-up activity
- Doctor performance
- Diagnosis analysis
- Billing amount
- Health insurance amount
- Bed occupancy
- Patient-level analysis

The project demonstrates an end-to-end **Business Intelligence and Data Analytics workflow** using Power BI.

---

# 🎯 Business Objective

The primary objective of this project is to provide a centralized dashboard for analyzing hospital operations and healthcare-related data.

The dashboard helps users explore:

- Patient and admission trends
- Hospital activity
- Doctor-related analysis
- Diagnosis patterns
- Billing and insurance amounts
- Bed occupancy
- Admission, discharge and follow-up dates
- Patient-level information

The interactive dashboard allows users to apply filters and explore different dimensions of the hospital data.
